# SEN MARCHÉ — Projet Front-End

## Technologies
- HTML5
- CSS3
- Bootstrap 5.3
- JavaScript
- Bootstrap Icons
- Google Fonts

## Pages
- index.html — Accueil
- produits.html — Catalogue, recherche et filtres
- producteurs.html — Producteurs
- commander.html — Formulaire de commande
- faq.html — FAQ Bootstrap Accordion
- contact.html — Formulaire de contact

## Installation
Aucune installation ni base de données n'est nécessaire.

1. Décompresser le dossier.
2. Ouvrir le dossier dans Visual Studio Code.
3. Ouvrir `index.html` avec un navigateur ou utiliser Live Server.

## Fonctionnalités
- Navbar responsive avec menu hamburger Bootstrap.
- Slider Hero.
- Catalogue avec 14 produits.
- Recherche et filtrage JavaScript.
- Panier simulé avec `localStorage`.
- Formulaire de commande avec validation.
- Formulaire de contact avec validation.
- FAQ Accordion.
- Design responsive.
- Prix en FCFA.
- Contexte sénégalais.

## Images
Les images de démonstration sont chargées depuis Unsplash via des URLs dans les fichiers HTML. Pour un rendu final hors ligne, téléchargez vos 23 photos locales et remplacez les URLs par `images/...`.

## Important
Il n'y a :
- aucune base de données ;
- aucun PHP ;
- aucun WordPress ;
- aucun WooCommerce ;
- aucun paiement réel.

Les commandes et contacts sont uniquement simulés côté navigateur, conformément au cahier des charges.
